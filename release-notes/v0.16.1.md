# v0.16.1 — Audit fixes and Playwright 1.65

Fixes from an audit of 0.16.0. Still twenty tools, Node 22 or newer.

## Security

- **`playwright-e2e-mcp ci` keeps the GitHub token away from your tests.**
  The GitHub Action passes a token with `pull-requests: write` so `ci` can post
  the report and suggested fixes. That token used to reach the Playwright and
  pytest processes too, so test code changed by a pull request could read it.
  `ci` now leaves `GITHUB_TOKEN` and `GH_TOKEN` out of every process it starts.
  If your tests really need one of them, list it in `PW_MCP_PASSTHROUGH_ENV`.
- **CI artifact downloads are capped by what is read.** `load-report` with a
  GitHub Actions or GitLab run URL trusted the `Content-Length` header and the
  artifact's listed size. A response without that header had no limit. The
  512 MB budget now counts the bytes actually received and stops the download
  when it is reached.

## Fixed

- **`--tools core` written as two arguments now works.** The server only read
  `--tools=core`, so a client config with `"--tools", "core"` silently loaded
  every tool. The server and `doctor` now read both forms.
- **The history server keeps saving after a failed save.** One failed write
  (a full disk, say) used to make every later upload fail until a restart.

## Changed

- **Playwright 1.65.0** (was 1.64.1). This covers the bundled `playwright-core`,
  the Docker image (`mcr.microsoft.com/playwright:v1.65.0-noble`) and the CI
  templates.
- **The CI templates pin the server version.** The GitLab, CircleCI, Azure,
  Bitbucket and CodeBuild templates now run `npx -y playwright-e2e-mcp@0.16.1`,
  so a new release only changes your pipeline when you bump it.
- **Releases only move `latest` forward.** npm's `latest` dist-tag and the
  Docker `:latest` tag go only to the newest stable release, so an older
  patch can no longer take them.
- The minimum `zod` is now 4.6.6 (GHSA-mrhx-c7xc-m3w5).

## Upgrading

`npx -y playwright-e2e-mcp` picks up 0.16.1 the next time your MCP client
starts it. For the GitHub Action, use `xsignon-secure/E2E@v0.16.1`. If you
copied one of the CI templates, change the version in its `npx` line.
