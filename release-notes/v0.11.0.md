# v0.11.0 — fewer tokens

This release cuts how many tokens the server costs an agent. Still nineteen
tools, Node 22 or newer, no new runtime dependencies. Numbers come from
`bench/token-benchmark.mjs` (characters ÷ 4); see `bench/RESULTS.md`.

## Changed

- **`inspect-page` defaults to the compact locator map.** Without `view` or
  `selector` it now returns the map of interactive elements with verified
  locators instead of the full DOM inventory. A block that repeats (product
  cards, table rows) is shown once and the rest are named. Text and CSS
  alternatives are left out, but test id, role, label and placeholder
  alternatives stay. On the benchmark storefront a page look costs 571 tokens
  instead of 3,589; Playwright MCP's snapshot of the same page is 2,286.
  `view: 'elements'` returns the full inventory, and it is still the default
  when `selector` is set.
- **Smaller tool definitions.** `tools/list` leaves out length and item limits,
  `propertyNames` and `$schema`. The server still validates every call against
  the full schema and names the limit when an argument breaks it. All tools:
  11,480 tokens the model reads per request (12,249 before); `core`: 2,266
  (2,428).

## New

- **Load tools on request: `--tools=auto` / `PW_MCP_TOOLS=auto`.** The tool list
  starts with the core fix loop plus `load-tools` (2,427 tokens). The agent calls
  `load-tools` with a profile (`triage`, `inspect`, `author`, `all`) or tool
  names. The tools are turned on for the rest of the session, and the client
  gets one `notifications/tools/list_changed`. `auto,inspect` starts with the
  tools listed after `auto` (here the inspect profile) instead of the core loop.
  This needs a client that refreshes its tool list. The hosted HTTP endpoint,
  which keeps no session state, lists every tool for `auto`. It is opt-in: the
  default is still every tool.
- **The benchmark counts what the model reads.** Tool definitions count each
  tool's name, description and input schema. The full `tools/list`, with output
  schemas that clients keep to themselves, is reported next to the table. The
  benchmark also compares `inspect-page` with `browser_snapshot`.

## Upgrading

The only behaviour change is the `inspect-page` default. Pass
`view: 'elements'` where you relied on the DOM inventory.

How to get 0.11.0:

- **`npx -y playwright-e2e-mcp`** (the README setup and what `init` writes):
  restart your MCP client; npx fetches 0.11.0 by itself.
- **Installed in the project:** `npm install -D playwright-e2e-mcp@latest`.
  **Globally:** `npm install -g playwright-e2e-mcp@latest`.
- **GitHub Action:** change `@v0.10.0` to `@v0.11.0` (the `version` input now
  defaults to 0.11.0).
- **Docker:** `docker pull ghcr.io/xsignon-secure/playwright-e2e-mcp:latest`.
- **Claude Desktop bundle:** download the new `.mcpb` below and open it.
- **Git clone:** `git pull && npm ci`.
- **Agent skill copied into a project:** run `npx -y playwright-e2e-mcp init`
  again.

`npx -y playwright-e2e-mcp doctor` says whether a newer version is out.
