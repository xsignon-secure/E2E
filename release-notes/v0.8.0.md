# v0.8.0 — Python suites, popups, crash recovery and the 2026 MCP revision

This release brings pytest-playwright projects to the same tools as Node ones,
lets the page tools follow popups and stay read-only, keeps the results of a run
that crashed, tightens the heal guard, and speaks the 2026-07-28 MCP revision.
Everything is free and part of the MIT package, as before. Still nineteen tools,
Node 22 or newer, no new runtime dependencies.

## New

- **pytest-playwright support.** A Python project (`pytest.ini`, a
  `[tool.pytest…]` table in `pyproject.toml`, pytest settings in `setup.cfg` or
  `tox.ini`, or a `conftest.py`) with no Node Playwright now works with
  `run-test` (background runs and the `ci` command included), `get-failure` and
  `list-tests`. Failures carry the test's own `file:line`, the code frame,
  expected and actual values, and the trace pytest-playwright kept, so
  `get-failure` shows the DOM at failure. Python comes from `PW_MCP_PYTHON`, the
  project's virtualenv, or `python3`; nothing is installed in your project.
  `suggest-fix` and `diagnose-flaky` say plainly that Python is not supported
  yet.
- **Popups and new tabs.** A `switchTab` step moves the page tools to a popup or
  new tab (the newest by default, a 1-based number, or text in its URL or title).
  Results list every open tab, and console messages come from all of them.
- **`blockWrites`** (or `PW_MCP_BLOCK_WRITES=1`) aborts POST, PUT, PATCH and
  DELETE requests that no mock or HAR answers, and lists them in the result, so
  inspecting a page cannot change real data.
- **Crashed runs keep their results.** Every run also loads a live reporter that
  records each test as it ends. When Playwright dies before writing its JSON
  report (a timeout, an out-of-memory kill), the failures that finished are
  rebuilt from it and the run is marked partial instead of reported as a crash
  with nothing in it.
- **MCP 2026-07-28.** The server offers the stateless 2026-07-28 revision next to
  the 2025 handshake (`PW_MCP_PROTOCOL=legacy` turns it off), sends cache hints
  on its lists, carries a title, description, website and icon in `serverInfo`,
  serves the bundled agent skill over the Skills extension
  (`skill://playwright-e2e-mcp/SKILL.md`; `PW_MCP_SKILLS=0` turns it off), and
  the HTTP bridge publishes a Server Card at `<mcp-url>/server-card` and
  `/.well-known/ai-catalog.json`. A `traceparent` in the request adds trace ids
  to the log lines.
- **Update check in `doctor`.** `npx -y playwright-e2e-mcp doctor` now asks npm
  for the latest version and, when yours is older, prints the update command for
  each way of installing. It is the only request the server makes besides the
  ones your tools ask for, it sends nothing but the package name, and
  `--offline` or `PW_MCP_NO_UPDATE_CHECK=1` skips it. The MCP server itself
  still never phones home.

## Changed

- **Heal guard:** an assertion wrapped in a `try` whose `catch` neither rethrows
  nor asserts is now a BLOCK (`assertion-swallowed`), and a web-first assertion
  without `await` is a WARN (`assertion-not-awaited`). A `try` that rethrows is
  no longer flagged.
- **Docs and examples:** `ARCHITECTURE.md`, a GitLab CI example, a reusable
  GitHub Actions workflow, a one-click core-tools install for Cursor, and an
  "Updating" section in the README.

## Upgrading

Nothing in your project needs to change. How you get 0.8.0 depends on how you
installed it:

- **`npx -y playwright-e2e-mcp`** (the README setup and what `init` writes):
  restart your MCP client. npx asks npm for the latest version each time it
  starts the server and fetches 0.8.0 by itself.
- **Installed in the project:** `npm install -D playwright-e2e-mcp@latest`.
  **Globally:** `npm install -g playwright-e2e-mcp@latest`.
- **GitHub Action:** change `uses: xsignon-secure/E2E@v0.7.0` to `@v0.8.0` (the
  Action's `version` input now defaults to 0.8.0).
- **Docker:** `docker pull ghcr.io/xsignon-secure/playwright-e2e-mcp:latest`.
- **Claude Desktop bundle:** download the new `.mcpb` below and open it.
- **Git clone:** `git pull && npm ci`.
- **Agent skill copied into a project:** run `npx -y playwright-e2e-mcp init`
  (or `npx skills add xsignon-secure/E2E`) again to refresh it.

If a 2026-revision client trips over the new handshake, set
`PW_MCP_PROTOCOL=legacy` and please open an issue.
