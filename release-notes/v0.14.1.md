# v0.14.1 — Proxy-safe sign-in limit, CI templates for four more platforms

A security and quality release from a review of 0.14.0. Upgrade if you run the
HTTP bridge behind a reverse proxy with `PW_MCP_TRUST_PROXY=1`, or pass
`{{env:…}}` secrets in `connect`. Still twenty tools, Node 22 or newer, no new
dependencies.

## Security

- **The sign-in limit can no longer be dodged behind a reverse proxy.** With
  `PW_MCP_TRUST_PROXY=1`, 0.14.0 read `X-Real-IP` and then the leftmost
  `X-Forwarded-For` entry. Both are sent by the client, so a guesser could
  change them on every request and never hit `PW_MCP_MAX_FAILED_AUTH`. Now:
  - `PW_MCP_TRUST_PROXY=1` (or `N` for N proxies in a row) reads the address
    the nearest proxy appended to `X-Forwarded-For`, counted from the right.
    This is what nginx (`$proxy_add_x_forwarded_for`), Caddy, Traefik and
    cloud load balancers send.
  - `PW_MCP_TRUST_PROXY=x-real-ip` reads only `X-Real-IP`, for a proxy that
    overwrites it (`proxy_set_header X-Real-IP $remote_addr`) and does not
    append to `X-Forwarded-For`. **If that is your setup, switch to this value.**
  - Vercel deployments are unchanged.
- **`{{env:…}}` secrets in `connect` only go to hosts you named.** A `connect`
  URL the agent passes (for example after reading a prompt-injected page) may
  only carry `{{env:…}}` values to `localhost`, the host of your own
  `PW_MCP_CONNECT`, or a host listed in the new `PW_MCP_CONNECT_HOSTS` (comma
  separated). Endpoints without secrets work as before.

## New

- **CI templates** for [Azure DevOps](../examples/azure-pipelines/azure-pipelines.yml),
  [CircleCI](../examples/circleci/config.yml),
  [Bitbucket Pipelines](../examples/bitbucket-pipelines/bitbucket-pipelines.yml) and
  [AWS CodeBuild](../examples/aws-codebuild/buildspec.yml): heal guard on pull
  requests, `ci` with flaky verdicts and verified fixes, reports kept as
  artifacts.
- **`check-mocks` reads JSON bodies written as strings:** Python
  `body='{"id": 1}'` (also triple-quoted and `r'…'`), JS `body: '{"id": 1}'` and
  template literals without `${…}`.

## Upgrading

- `npx -y playwright-e2e-mcp` picks up 0.14.1 the next time your MCP client
  starts it.
- If your agent passes `connect` URLs with `{{env:…}}` to a cloud grid, add the
  grid's host to `PW_MCP_CONNECT_HOSTS` (or set it as `PW_MCP_CONNECT`).
