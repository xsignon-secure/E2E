# v0.15.0 — Every workflow for pytest-playwright suites

pytest-playwright projects now get the three tools that were TypeScript-only.
Still twenty tools, Node 22 or newer, no new dependencies.

## New for Python

- **`diagnose-flaky`** repeats pytest tests with reruns off and gives the same
  per-test verdicts (FLAKY, CONSISTENTLY FAILING, NOT REPRODUCING). Each
  repetition is its own pytest process. `isolate: true` runs the tests in
  parallel with pytest-xdist (`-n`, `workers` default 4) and then alone, to tell
  a shared-state bug from a race inside the test; it says so if pytest-xdist is
  not installed. `order` needs Playwright's `--shuffle` and stays Node only.
- **`audit-tests`** reads `test_*.py` and `*_test.py` with Python rules:
  `wait_for_timeout` and `time.sleep`, one-shot `assert loc.is_visible()` /
  `assert loc.inner_text() == …` / `assert page.url == …`, calls an `async def`
  test forgets to await, `force=True`, `networkidle`, `query_selector` and
  other element handles, layout selectors, `timeout=0` and hard-coded local
  URLs. `fix: true` rewrites one-shot asserts to `expect(loc).to_be_visible()`,
  `to_have_text`, `to_have_value`, `to_have_count`, `to_have_attribute` or
  `to_have_url` (when the module imports `expect`), adds missing `await`s, and
  verifies with pytest, restoring the files if the run fails.
- **`generate-e2e-test`** writes `tests/generated/test_<name>.py` with Python
  locators (`page.get_by_role("button", name="Buy")`). With `steps` it walks
  the flow on the live page, writes the module with URL and aria-snapshot
  assertions, and runs it once with pytest. The start URL comes from `pageUrl`
  or `base_url` in `pytest.ini` / `pyproject.toml` (pytest-base-url); a saved
  login becomes a `browser_context_args` fixture.

## Fixed

- **pytest runs with `-n` (pytest-xdist) counted every test twice.** The
  results plugin wrote each test from the worker and again from the
  controller, so `run-test` with `args: ["-n=4"]` doubled pass and fail counts.
  The controller now leaves per-test results to the workers.

## Upgrading

`npx -y playwright-e2e-mcp` picks up 0.15.0 the next time your MCP client
starts it. For `isolate` in a Python project: `pip install pytest-xdist`.
