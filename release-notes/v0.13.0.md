# v0.13.0 — CI runs, remote browsers and Python fixes

The second half of the Playwright gap list: fewer manual steps between a red CI
job and a verified fix, browsers that live somewhere else, and `suggest-fix`
for pytest suites. Still twenty tools, Node 22 or newer, no new runtime
dependencies.

## New

- **`load-report` takes a CI run URL.** Pass a GitHub Actions run
  (`https://github.com/<owner>/<repo>/actions/runs/<id>`) or a GitLab job
  (`https://<host>/<group>/<project>/-/jobs/<id>`) as `report`. The run's
  report-like artifacts are downloaded into `.playwright-e2e-mcp/ci/<run>/`,
  the JSON report or blob reports are found in them, traces are matched, and
  the commit, branch and run link come from the CI API. It uses your own token
  from the environment (`GITHUB_TOKEN` / `GH_TOKEN`, or `GITLAB_TOKEN` /
  `CI_JOB_TOKEN`), sends it only to the API host the URL names, and fetches
  nothing unless you pass a URL. GitHub Enterprise and self-managed GitLab
  work from their URLs.
- **Remote browsers and device clouds.** The page tools (`inspect-page`,
  `validate-selector`, `compare-visual-state`, `audit-accessibility`,
  `audit-performance`) take `connect`: a Playwright server endpoint
  (`ws://` / `wss://`: `npx playwright run-server`, Browserless, a device
  cloud's Playwright endpoint) or `cdp:` + a Chrome DevTools URL.
  Access keys go in the environment and are written as `{{env:E2E_…}}`; the
  endpoint is redacted from errors. `PW_MCP_CONNECT` sets a default. Local
  server only; the HTTP bridge refuses it.
- **`suggest-fix` patches pytest-playwright specs.** Python locators in errors
  are read, healed against the DOM at failure like TypeScript ones, written
  back in Python syntax (`page.get_by_role("button", name="Checkout")`) and
  verified with a pytest re-run that reverts the edit if still red.
- **Testing AI chat and streaming UIs.** The agent skill's writing guide has a
  new section: mock the model with a fixed event stream (or
  `routeWebSocket`), wait for the UI's done signal instead of text, assert on
  shape against live models, and test cut-off streams, 429s and Stop.

## Changed

- `load-report` is annotated open-world, because it can download from CI.
- `{{env:NAME}}` tokens never resolve the server's own `PW_MCP_*` settings.
- A few string-matching regexes were made linear (CodeQL).
- All twenty tool definitions cost the model about 12,050 tokens per request
  (11,880 before); `core` is unchanged at 2,323.

## Upgrading

No breaking changes. How to get 0.13.0:

- **`npx -y playwright-e2e-mcp`** (the README setup and what `init` writes):
  restart your MCP client; npx fetches 0.13.0 by itself.
- **Installed in the project:** `npm install -D playwright-e2e-mcp@latest`.
  **Globally:** `npm install -g playwright-e2e-mcp@latest`.
- **GitHub Action:** change `@v0.12.0` to `@v0.13.0` (the `version` input now
  defaults to 0.13.0).
- **Docker:** `docker pull ghcr.io/xsignon-secure/playwright-e2e-mcp:latest`.
- **Claude Desktop bundle:** download the new `.mcpb` below and open it.
- **Git clone:** `git pull && npm ci`.
- **Agent skill copied into a project:** run `npx -y playwright-e2e-mcp init`
  again.

`npx -y playwright-e2e-mcp doctor` says whether a newer version is out.
