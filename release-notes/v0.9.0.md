# v0.9.0 — everything free, including team history

playwright-e2e-mcp no longer has a paid tier. The CI run history service that was
planned as a paid "Pro" add-on is now part of this repository, MIT like the rest,
and you host it yourself. Every tool, the GitHub Action, the `ci` command and the
history server are free. Still nineteen tools, Node 22 or newer, no new runtime
dependencies in the npm package.

## New

- **Self-hosted history server** (`history-server/`). It collects the runs every CI
  job and laptop records, so `analyze-history` ranks flaky and broken tests across
  all of them and names the commit where each went bad, and its dashboard shows the
  same. Run it with one `docker run` (runs kept in a volume), plain Node 22 (runs
  kept in a JSON file), or on a free Vercel or Azure account with Postgres. Whoever
  hosts it lists tokens in `HISTORY_TOKENS`; each `team:token` pair gets its own
  space, so teams never see each other's runs. No accounts, no billing, nothing
  sent anywhere but the server you run. See `history-server/README.md`.

## Changed

- **New setting names:** `PW_MCP_HISTORY_URL`, `PW_MCP_HISTORY_TOKEN` and
  `PW_MCP_HISTORY_PROJECT`, and the Action's `history-url` and `history-token`
  inputs. Without them nothing changes and no request is made, as before.
- The README, tool reference, skill and example workflow no longer mention a paid
  plan.

## Upgrading

Nothing breaks. The 0.7/0.8 names `PW_MCP_PRO_KEY`, `PW_MCP_PRO_URL`,
`PW_MCP_PRO_PROJECT` and the Action's `pro-key` / `pro-url` keep working, and the
`upload` command still reads its old `pro-upload.json` marker, so it does not
resend runs it already sent. Switch to the new names when convenient.

How to get 0.9.0:

- **`npx -y playwright-e2e-mcp`** (the README setup and what `init` writes):
  restart your MCP client; npx fetches 0.9.0 by itself.
- **Installed in the project:** `npm install -D playwright-e2e-mcp@latest`.
  **Globally:** `npm install -g playwright-e2e-mcp@latest`.
- **GitHub Action:** change `@v0.8.0` to `@v0.9.0` (the `version` input now
  defaults to 0.9.0).
- **Docker:** `docker pull ghcr.io/xsignon-secure/playwright-e2e-mcp:latest`.
- **Claude Desktop bundle:** download the new `.mcpb` below and open it.
- **Git clone:** `git pull && npm ci`.
- **Agent skill copied into a project:** run `npx -y playwright-e2e-mcp init`
  again.

`npx -y playwright-e2e-mcp doctor` says whether a newer version is out.
