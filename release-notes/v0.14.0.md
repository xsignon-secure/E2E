# v0.14.0 — Faster checks, masked visuals, fixes proven on every browser

Six gaps from a review of the tools against everyday QA work. Still twenty
tools, Node 22 or newer, no new dependencies.

## New

- **`run-test` `changed`.** Run only the test files your changes affect:
  `changed: true` for uncommitted changes, or a git ref such as
  `"origin/main"`. It uses Playwright's `--only-changed`, which follows
  imports, so a change in `src/checkout.ts` runs the specs that import it.
  Git refs that look like options are refused.
- **`suggest-fix` `verifyAllProjects`.** After applying a fix, re-run the test
  on every project in `playwright.config` (for example chromium, firefox and
  webkit) and revert unless all of them pass, so a fix that only works in one
  browser is never kept.
- **`compare-visual-state` `mask`.** Selectors or locators painted one flat
  color in both images, so clocks, ad slots and random avatars never count as
  a change. The masks are saved with the baseline and reused by later compares.
- **`blockResources` for the page tools.** Skip `image`, `media`, `font`,
  `stylesheet` and `trackers` (common analytics, tag and ad hosts) for faster
  checks that don't call third parties. Mocks and HAR replay still answer
  first. `PW_MCP_BLOCK_RESOURCES` sets a default.
- **`offline` for the page tools.** Go offline once the page has loaded,
  before the steps run, to check offline banners and retry buttons.

## Safer defaults

- **Home-folder guard.** When an MCP client starts the server in your home
  folder or `/` (no working directory set), a `projectRoot` the agent picks
  must be a real project: no hidden folders such as `~/.ssh` or `~/.aws`, and
  a `package.json`, Playwright config or pytest config must be there. The
  server also logs a warning at startup. Folders in `PW_MCP_ALLOWED_ROOTS`
  are trusted as they are.
