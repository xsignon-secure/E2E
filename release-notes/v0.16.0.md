# v0.16.0 — See what your tools cost

`doctor` now tells you how many tools your MCP client loads and what their
definitions cost the model on every request. Still twenty tools, Node 22 or
newer, no new dependencies.

## New

- **`doctor` Tools check.** Shows how many tools are exposed and their token
  cost per request (characters ÷ 4, the same rule as the benchmark), for
  example `20/20 tools exposed (~12.8k tokens / request)`. When every tool is
  loaded it warns and suggests `--tools=core` or `--tools=auto`. It reads the
  setting where the server gets it: `--tools=` or `PW_MCP_TOOLS` in the client
  configs `doctor` already finds (`.mcp.json`, Cursor, VS Code, Gemini CLI,
  Codex, Windsurf), or `PW_MCP_TOOLS` in your shell. Unknown tool or profile
  names get a warning. Thanks to @chiragjangiir for the first version (#69,
  closes #40).

## Changed

- The benchmark was re-run on 0.16.0: tool definitions cost 12,762 tokens with
  all tools, 2,433 with `core` and 2,601 with `auto`. The README and
  `bench/RESULTS.md` now match what `doctor` reports.

## Upgrading

`npx -y playwright-e2e-mcp` picks up 0.16.0 the next time your MCP client
starts it. Run `npx -y playwright-e2e-mcp doctor` in your project to see what
your tool setting costs.
